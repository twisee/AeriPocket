# AeriPocket 1.0.3 · 支付漏记修复

## 修改

- 支付宝：付款码/首页背景与成功结果同时存在时，优先定位成功容器；结构缺失时按诊断中严格完整的结果序列定位。支持“交易方式”支付工具标签。避免首页消息、旧详情、零元以及变化的背景造成误记或重复候选。
- 通知：进程冷启动、回到应用前台、服务断开时，检查已授权但未连接状态，按退避间隔请求系统恢复。请求不等于连接成功，诊断记录真实回调和恢复过程。
- 抖音：观察到支付SDK窗口后，最多12秒继续空页补采；事件源或整页里短暂出现的成功标题先交给原解析/去重流程。结算金额、支付窗口出现本身均不触发入账。

## 安装与复测

版本码13，包名沿用 `com.twisee.wallet.eco`，签名沿用既有侧载包；直接覆盖安装，保留账本，不需要卸载。安装后打开应用一次，确认自动采集和页面采集仍开启、通知监听状态已连接；诊断建议继续开启。

下次正常使用支付宝付款码或抖音商城支付后，检查账单是否出现且金额正确、同笔是否重复。若仍漏记，保留诊断，记录付款时间及金额后再导出。系统拒绝重连或支付页面始终不提供可访问文字时，仍可能无法识别。

此版本修正后续采集，不会自动把诊断里的旧支付补进手机账本。桌面回放与测试不能代替小米手机实际通知送达、支付窗口可读性和覆盖安装验证。
