# AeriPocket 1.5.4

- 概览增加“预算使用／全部消费”切换。预算金额、合计、圆环和进度统一排除不计入预算的支出；全部消费仍包含这些支出并显示分类占比。
- 移除预算列表右侧重复百分比，金额右对齐，进度旁显示实际已用百分比；达到或超过100%时条形填满，超支另列超出金额。
- 分类标记、圆环和进度条保持同色，超支用醒目文字提示；未设置分类预算不计算预算使用率。
- 保留5条及以内不吸顶、超过5条固定圆环的滚动方式；顶栏不重复显示日期，周期仍通过原日期工具条选择。
- 修复13项静态检查错误，包含通知权限撤回处理、Android 8–10消息通知读取、快捷设置入口兼容、图片异步加载写法、英文快捷方式文字与可选电话硬件声明。
- 同步应用内帮助与使用说明。
