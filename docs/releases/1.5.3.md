# AeriPocket 1.5.3

## 分类预算

保留概览圆环与原分类清单，在设置了预算的分类下加入使用进度条。条长按计入预算的支出计算：不计入预算的支出不消耗额度，AA及退款沿用原预算规则；原清单金额和占比仍表示实际支出。接近用完变黄，超支变红，未设预算不显示虚假的预算进度。

分类超过5条时固定圆环，下面列表正常滚动；5条及以内使用普通布局，不增加额外吸顶和大段滚动余量。上方收支卡、日/月支出日历保留。

## 记账与编辑

- 日期、24小时时分入口常驻，新增和编辑都能修改。新账默认打开时的当前时间，保存采用所显示的日期时间；打开旧账保留原时间和已选分类。
- 最多4个分类直接点选；更多时显示前三项及“全部 N”，在可搜索、可滚动的分类网格选择。当前选中分类始终显示在分类栏右侧。
- 编辑页默认一页，右上角提供退款/撤销退款和删除，底部只有保存修改。删除仍需确认；有未保存修改时先保存再退款。小屏、大字号或键盘弹出时可滚动表单，保存按钮保持可达。
- 取消分钱包选择、管理和余额入口，包括记账、导入、待确认及悬浮确认卡。旧账的内部关联保留，不删除历史数据；支付来源仍用于自动识别。

## 商户联想与本次例外

输入商户时可选择已有规则中的商户，并沿用对应收支方向的分类。优先级：本次明确手选分类、商户默认、初始分类。打开旧账不会把曾经的例外改回默认；改成另一个商户时可沿用新商户规则。

“设为该商户的默认分类”默认不勾选。学校食堂通常属于餐饮，本笔手选日常后直接保存只修改这一笔；只有主动勾选并保存，才更新规则及同商户同方向的历史分类。改变商户或手选分类会清掉先前的默认勾选，避免误更新。

原“命中次数”是学习次数，不能代表实际使用次数；现改为“关联账单 N 笔”，按现有账本同商户、同方向的正式账单统计，包含本次例外。删除账单后数量随之减少；原始退款事件不重复计数。

## 导出账单

入口：个人 → 导入 / 导出 → 导出账单。可导出全部账单或指定日期区间（含首尾两天），由系统文件选择器指定保存位置。导出完整范围，不受流水分页影响，不自动上传。

格式为带UTF-8 BOM的CSV，列包含：日期时间、收支、分类、金额（原金额）、商户、备注、来源、已退款金额、实付金额、退款状态、AA人数、是否计入预算。金额精确到两位小数；保留逗号、双引号及多行备注。原始退款事件不重复作为收入导出，退款信息在原支出行中列出。

不同软件需要按其导入模板映射字段，尤其注意“金额”为原金额、“实付金额”为扣除退款后的金额；AA人数另列，实付金额不再次除人数。此CSV用于迁移和查看，不是AeriPocket完整备份恢复格式。
