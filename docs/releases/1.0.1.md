# AeriPocket 1.0.1

2026-11-14 · versionCode 11

## 更新内容

- 快速记账增加加、减、乘、除、清空、退格及等号，金额区同时显示算式和结果；不按等号也可以直接保存结果。
- 修复填写商户或备注后无法点击上方金额返回修改的问题，切换时保留已填信息。
- 运算符居中，退格图标重新绘制；键盘随当前主题色和深色模式变化。
- 保留原有金额、分类、完成步骤图标，不显示运算顺序说明。
- 计算按正常四则运算顺序处理，中间使用精确分数，最终结果四舍五入到分；无效算式、除以零、非正金额或超限金额无法保存。

## 安装

从 [本版本发布页](https://github.com/twisee/AeriPocket/releases/tag/v1.0.1) 下载 `AeriPocket-1.0.1.apk`。包名和签名证书与 1.0.0 一致，可直接覆盖安装。

## 验证与限制

6 项计算器测试、1 项商户/备注与金额切换和保存界面测试、1 项原有支出收入编辑删除流程测试全部通过；release 构建和 lintVitalRelease 检查通过。

界面测试在 390×844、字体倍率 1.25 下执行，检查了青蓝、纯白、暖金、紫色及青蓝深色截图。本次未重跑完整测试套件和完整 lintDebug，也未在实际手机上安装验证；手机输入法切换和手感仍需设备验证。
